# Высокоуровневые методы программирования и информатики

Лабораторные работы по дисциплине. Автор: Роман Хадралиев

Консольное приложение на Kotlin для проверки прав доступа пользователей
к иерархическим ресурсам. В ходе развития проекта данные (пользователи, ресурсы, правила
доступа) были вынесены из кода в реляционную базу данных **H2**. Пароли хранятся 
в виде SHA-256-хэшей с солью. Программа работает тихо и сообщает результат через код 
возврата; вывод на экран возможен только при запросе справки.

---

## Требования

- JDK 11 или выше;
- компилятор Kotlin `kotlinc`, доступный в `PATH`;
- библиотеки в папке `lib/`:
  - `kotlinx-cli-jvm-0.3.5.jar`
  - `h2-2.2.224.jar` (драйвер базы данных)

---

## Работа с базой данных

Перед первым запуском необходимо инициализировать базу данных. Скрипт создаст папку `data/`, 
применит SQL-скрипты из `scripts/sql/` и наполнит базу тестовыми данными (Алиса, Боб, Кэрол).

```bash
./scripts/init-db.sh
```

*Файл базы данных будет храниться локально по пути `data/app_db.mv.db`.*

---

## Сборка

```bash
./scripts/build.sh
```

Скрипт компилирует исходники, подключает `kotlinx-cli` и драйвер `H2`, 
и упаковывает результат вместе с Kotlin runtime в `app.jar`.

---

## Запуск

```bash
java -jar app.jar --login <логин> --password <пароль> --action <действие> \
                  --resource <путь> --volume <объём>
```

Пример:

```bash
java -jar app.jar --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Код возврата можно посмотреть сразу после запуска:

```bash
java -jar app.jar --login alice --password qwerty --action read --resource A --volume 10
echo "exit code: $?"
```

Справка:

```bash
java -jar app.jar --help
```

или

```bash
java -jar app.jar -h
```

### Поддерживаемые аргументы

| Короткий | Длинный      | Описание                                              |
|----------|--------------|-------------------------------------------------------|
| `-l`     | `--login`    | Логин пользователя                                    |
| `-p`     | `--password` | Пароль пользователя                                   |
| `-a`     | `--action`   | Действие над ресурсом: `read`, `write`, `execute`     |
| `-r`     | `--resource` | Путь до ресурса, сегменты разделены точками           |
| `-v`     | `--volume`   | Запрашиваемый объём ресурса (целое положительное)     |
| `-h`     | `--help`     | Показать справку                                      |

## Тестирование

### Интеграционные тесты (черный ящик)
```bash
./scripts/integration_test.sh
```
Скрипт последовательно запускает программу по одному кейсу на каждый
код ответа, сравнивает фактический код с ожидаемым и печатает
`OK` или `FAIL` для каждого кейса, а в конце — итоговое количество
успешных тестов.

### Модульные тесты (JUnit 5)
Проект покрыт 99 модульными тестами, которые проверяют бизнес-логику, 
доменные модели и работу репозиториев (с использованием фейков).
```bash
./scripts/build_tests.sh   # Сборка тестов
./scripts/run_unit_tests.sh # Запуск тестов
```

| Описание                                | Код ответа |
|-----------------------------------------|------------|
| Успешное выполнение                     | 0          |
| Запрошена справка                       | 1          |
| Неверный пароль                         | 2          |
| Неверный логин                          | 3          |
| Неизвестное действие над ресурсом       | 4          |
| Нет доступа                             | 5          |
| Несуществующий ресурс                   | 6          |
| Некорректный формат ресурса или объёма  | 7          |
| Превышение максимального объёма         | 8          |
| **Ошибка подключения к базе данных**    | **9**      |
| **Ошибка SQL-запроса**                  | **10**     |
